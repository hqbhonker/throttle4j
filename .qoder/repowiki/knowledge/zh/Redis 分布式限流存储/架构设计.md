- 核心实现 `RedisRateLimitStore` 实现了 `RateLimitStore` 接口，通过 Lettuce 客户端与 Redis 交互。
- 采用 Lua 脚本（`fixed_window.lua`, `sliding_window.lua`, `token_bucket.lua`）在 Redis 端原子化执行限流逻辑，确保分布式环境下的数据一致性。
- `FallbackRateLimitStore` 提供装饰器模式的故障转移能力，当主存储（Redis）异常时自动降级到备用存储（如内存存储）。
- `RedisRateLimitStoreBuilder` 提供流式 API 用于构建配置化的存储实例。
- 依赖 `throttle4j-core` 定义核心接口与配置，依赖 `lettuce-core` 进行 Redis 通信。
