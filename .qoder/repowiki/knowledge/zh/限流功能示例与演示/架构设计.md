- 入口点：`SpringBootExampleApplication` 启动 Web 服务，`BasicUsageExample` 运行纯 Java 演示。
- Web 层：`ExampleController` 通过 `@RateLimit` 注解在 REST 接口上应用不同算法（滑动窗口、令牌桶）；`ExampleExceptionHandler` 统一捕获 `RateExceededException` 并返回 HTTP 429。
- 配置层：`application.yml` 定义默认限流策略及内存存储类型。
- 依赖方向：模块依赖 `throttle4j-spring-boot-starter` 实现自动配置，依赖 `throttle4j-redis`（虽示例主要用内存），以及 `spring-boot-starter-web`。
